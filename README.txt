PHYSICS ACADEMY — STARTER WEBSITE

WHAT IS INCLUDED
- index.html: app screens
- style.css: mobile-friendly design
- script.js: demo login and sample interactions

IMPORTANT
This is a front-end starter/demo. The name-based login is NOT secure authentication.
Do not use it for real student records, private marks, or attendance yet.
We will add Firebase Authentication and a database in a later step.

PUBLISH USING GITHUB PAGES
1. Create/sign in to a GitHub account at https://github.com/
2. Click the + menu (top right) > New repository.
3. Name it: physics-academy
4. Choose Public for the simplest free GitHub Pages setup. Do not upload real student data.
5. Create repository.
6. On the repository page, click Add file > Upload files.
7. Extract this ZIP on your computer first. Upload index.html, style.css, script.js, and README.txt from inside the folder. Do not upload only the ZIP.
8. Click Commit changes.
9. Open repository Settings > Pages.
10. Under Build and deployment, choose Deploy from a branch.
11. Select branch main and folder /(root), then Save.
12. Wait a few minutes and refresh Settings > Pages. GitHub will show the live website URL.

DESKTOP SHORTCUT (CHROME / EDGE)
1. Open the live website.
2. In Chrome: click ⋮ > Cast, save and share (or More tools, depending on version) > Create shortcut.
   In Edge: click ⋯ > Apps > Install this site as an app, if available.
3. Name it Physics Academy and confirm.
4. The shortcut opens the website like an app. The site still needs internet to load.
